# 🎒 暑假学习小助手

给 **7-8 岁小朋友**（小学一二年级）的假期辅助学习工具。

## ✨ 功能

- 📖 **语文**：名著阅读（童话、成语、古诗、快乐读书吧）
- 🧮 **数学**：计算题（口算 + 笔算 + 应用题，含动态生成器）
- 🔤 **英语**：单词背诵（200词，7大主题，看图/配对/拼写）
- 📝 **练习+考核**：每 7 天一次考核，共 7 次周考 + 1 次期末
- ⭐ **积分激励**：6 级称号、8 枚徽章、10 张贴纸
- 📱 **跨平台**：手机/平板/电脑浏览器都能用
- 📴 **离线可用**：PWA 支持，添加到手机主屏幕

## 🚀 快速开始

### 方法一：直接打开
1. 下载本项目所有文件
2. 用浏览器打开 `index.html`

### 方法二：部署到 GitHub Pages（推荐）
1. 在 GitHub 创建新仓库
2. 推送本项目所有文件
3. 在仓库 Settings → Pages 中启用
4. 访问 `https://你的用户名.github.io/仓库名/`

### 方法三：本地服务器
```bash
# 用 Python
python -m http.server 8080
# 用 Node
npx serve .
```

## 🛠️ 技术栈

- 纯 HTML/CSS/JS（零依赖、零构建）
- PWA（渐进式 Web 应用）
- localStorage（本地数据存储）
- 设计风格：浅色手写风、小书虫吉祥物、彩蛋系统

## 📝 数据说明

- 所有学习进度保存在浏览器 localStorage 中
- 可以在"设置"页面导出/导入进度 JSON 文件
- 切换设备需手动导入导出

## 🎨 设计理念

遵循用户设计偏好：浅色、活泼、手写感、不规则、"活人感"。
❌ 不用：深色背景、紫蓝渐变、毛玻璃效果
✅ 使用：奶油白背景、铅笔橙主色、纸张纹理、"小书虫"吉祥物
